# 👔 WORKFORCE

<a name="top"></a>

**An AI workforce for the ventures the owner runs and for the owner's own life.**

_One file per agent. Rendered for every app. Routed through one hub._

</div>

---

## 💡 What This Folder Is For

Each agent is one Markdown file: flat frontmatter, then the instructions it works from. The [Chief of Staff](Chief%20of%20Staff.md) routes every message between departments, the [Knowledge Vault Manager](Knowledge%20Vault%20Manager.md) alone writes the owner's vault, and each department folder, named as in the venture template of tannergolden/knowledge, holds its charter and its team. [`Protocol.md`](Protocol.md) is the rule set every agent carries, and [`Repository Standards.md`](<Repository Standards.md>) the map of the owner's engineering standards that every agent changing files carries. Administration is the executive team: the ⭐ Chief Executive Officer and the Chiefs, to whom every other department's Director reports.

[`setup/`](setup/README.md) holds the prompt that turns a session or a Bot into the Chief of Staff, for the Grok Bot app and for a terminal, each with the steps it follows to set the workforce up and to keep it current.

`.github/scripts/workforce.py` checks the folder and renders it for each environment. How it is built, why each department has the seats it has, how agents talk, and how to install it locally, in the cloud and on Grok: [The Workforce](../docs/technical/The-Workforce.md).
