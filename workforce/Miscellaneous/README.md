## 💡 What This Folder Is For

The venture template keeps a `Miscellaneous/` folder for what fits no department, so the workforce keeps one too, and keeps it empty of agents: it is a place to file, not a department. The Chief of Staff routes such work to the Director whose remit is closest, or asks the owner, and the Knowledge Vault Manager files the result and proposes moving it once a department fits. Why it has no team: [The Workforce](../../docs/technical/The-Workforce.md).
