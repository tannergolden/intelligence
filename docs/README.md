## 💡 How To Read These

`AGENTS.md` at the repository root is **the law** and the only file with rules in it. Nothing here overrides it. These documents explain how the publisher works, why each boundary sits where it does, and what was measured rather than assumed.

Read [Scope & Boundaries](Scope-&-Boundaries.md) first if you are about to add something. It is the document that exists to stop this repository growing a second law.
